# Raum & Routine

Kostenfreier, statischer Website-Entwurf für ein deutschsprachiges Pinterest-Affiliate-Projekt.

## Status
- Website-Entwurf vorhanden
- Keine Affiliate-Links und keine Tracking-Skripte
- **Nicht produktiv veröffentlichen**, bevor Impressum, Datenschutzerklärung, Kontaktangaben und rechtliche Prüfung abgeschlossen sind
- Pinterest-Business- und Rakuten-Publisher-Konten sowie Händlerfreigaben stehen aus

## Kostenloses Hosting
Nach rechtlicher Fertigstellung GitHub Pages über **Settings → Pages → Deploy from a branch → main / (root)** aktivieren. Die Adresse ist dann voraussichtlich https://snycr.github.io/raum-und-routine/ .

## Automatisierung
GitHub Actions prüft Änderungen an der statischen Website. Die Pinterest-Veröffentlichung ist nicht automatisiert; dafür ist ein zugelassener Veröffentlichungsweg nötig.

## Redaktion
Die Datei content/pinterest-plan.csv enthält sechs Ideen für erste Pins. Vor Veröffentlichung Inhalte und Grafiken individuell prüfen. Keine fremden Produktbilder ohne passende Nutzungsrechte verwenden.

## Affiliate
Nur freigegebene Händlerprogramme und gültige Affiliate-Links verwenden; Werbung deutlich kennzeichnen. Keine Provisionen versprechen.
